# Windows 双网卡流量分析网关设计

## 目标

构建一个可在 Windows 电脑上运行的 exe 软件。电脑使用双网卡串接在任意路由器和下级用户网络之间，软件作为二级网关，统计并管控经过该电脑的局域网用户流量。

软件用于合法网络管理、运维审计、带宽控制和安全告警。它不伪装第三方设备，不进行 HTTPS 解密，不查看聊天内容、网页正文、账号密码或其他私人内容。

## 部署拓扑

```text
上级路由器 LAN
  -> Windows 电脑网卡 1，WAN 侧
  -> 本软件后台网关服务
  -> Windows 电脑网卡 2，LAN 侧
  -> 下级交换机 / AP / 用户路由器 / 用户设备
```

默认网段示例：

```text
上级路由器：192.168.1.1/24
电脑 WAN：192.168.1.2/24，网关 192.168.1.1
电脑 LAN：10.10.10.1/24
下级用户：10.10.10.0/24，网关 10.10.10.1
```

软件只统计和管控经过电脑 LAN/WAN 两张网卡转发的设备。没有经过该电脑的同级设备不在管理范围内。

## 产品形态

第一版交付为 Windows exe 安装包，包含：

- 后台网关服务：负责转发、NAT、DHCP、DNS 代理、连接跟踪、限速和策略执行。
- 桌面管理界面：负责配置、设备列表、流量图表、安全告警、策略管理和报表导出。
- 本地数据存储：保存设备、流量、域名、策略、告警和报表数据。

后台服务随 Windows 启动，管理界面可独立打开和关闭。关闭管理界面不影响转发服务运行。

## 功能范围

### 设备管理

- 自动发现下级网络设备。
- 展示 IP、MAC、主机名、网卡厂商、在线状态、首次出现时间、最后活跃时间。
- 支持设备备注、分组、固定 IP 绑定。
- 支持一键拉黑、限速、加入白名单。

### 实时流量统计

- 统计每台设备实时上行速率、下行速率、总上传、总下载。
- 统计当前连接数、活跃目标 IP、端口、协议。
- 展示全网总速率、在线设备数量、Top 流量设备。
- 支持按设备、分组、时间段筛选。

### 域名、IP 和协议分析

- 内置 DNS 代理，记录设备发起的 DNS 查询。
- 展示访问域名、目标 IP、目标端口、协议类型。
- 使用离线 GeoIP 数据库标记目标国家/地区。
- 基于 DNS、端口和连接特征做基础应用分类，例如网页、视频、游戏、P2P、远程连接、DNS、邮件。

### 安全检测

- 检测异常连接数、端口扫描、内网扫描、DNS 异常请求。
- 基于规则库识别挖矿域名/IP、恶意地址、可疑 C2 地址、P2P 高风险行为。
- 告警包含时间、设备、风险等级、命中规则、目标地址和建议处置。
- 支持告警确认、忽略、拉黑、限速。

### 管控策略

- 单设备限速。
- 分组限速。
- 域名黑名单和白名单。
- IP 黑名单和白名单。
- 端口封禁。
- 时间段上网控制。
- DNS 上游服务器配置。
- DNS 分类拦截基础能力。

第一版策略目标是基础可用和稳定，复杂 DPI 分类和高级 QoS 作为后续增强。

### 报表

- 用户/设备流量排行。
- 域名访问排行。
- 协议/端口排行。
- 国家/地区排行。
- 安全告警报表。
- 支持按今天、昨天、近 7 天、本月、自定义时间段查询。
- 支持导出 CSV，后续可增加 Excel 和 PDF。

## 界面设计

界面采用现代网络安全管理后台风格，支持浅色和深色主题。整体视觉克制、清晰，适合长时间监控。

主要页面：

- 首页仪表盘：总上下行、在线设备、连接数、告警数、Top 设备、实时曲线。
- 设备管理：设备表格、在线状态、速率、流量、备注、分组、快捷处置。
- 流量分析：实时曲线、连接明细、协议分布、目标国家/地区。
- 域名分析：DNS 查询记录、域名排行、分类、黑白名单入口。
- 安全告警：风险列表、等级筛选、规则命中、处置动作。
- 策略管理：限速、黑白名单、端口封禁、时间段规则、DNS 配置。
- 报表中心：按用户、时间、应用、风险维度生成报表。
- 系统设置：网卡选择、LAN 网段、DHCP 地址池、上游 DNS、数据保留周期、规则库更新。

## 技术架构

### 核心组件

- Gateway Service：Windows 后台服务，负责网关转发、NAT、DHCP、DNS 和策略执行。
- Packet Engine：基于 Windows Filtering Platform 或 WinDivert/Npcap 采集连接元数据。
- Flow Aggregator：把包和连接事件聚合为设备流量、连接、域名、告警。
- Policy Engine：执行限速、黑白名单、端口封禁、时间段策略。
- DNS Proxy：处理下级用户 DNS 请求，记录域名并执行域名策略。
- UI App：桌面管理界面或本地 WebView 管理界面。
- Local Database：SQLite 或 DuckDB，保存配置和统计数据。

### 推荐技术

- 前端界面：Tauri / Electron / WebView2 + React。
- 后台服务：Go、Rust 或 C#。
- 数据库：SQLite 用于配置和事件，DuckDB 可用于报表分析。
- 抓包/过滤：Windows Filtering Platform 优先；如开发成本过高，第一版可选 WinDivert。
- 地理位置库：离线 GeoIP 数据库。
- 规则库：本地 JSON/SQLite 规则，支持后续更新。

## 数据模型

核心表：

- devices：设备、MAC、IP、主机名、厂商、分组、备注、状态。
- flows：连接记录，包含源设备、目标 IP、端口、协议、上下行字节、开始/结束时间。
- dns_queries：DNS 查询记录，包含设备、域名、解析 IP、时间、动作。
- traffic_rollups：按分钟/小时聚合的设备流量。
- policies：策略配置，包含类型、目标、动作、优先级、启用状态。
- alerts：告警记录，包含风险等级、设备、规则、证据、处置状态。
- reports：报表任务和导出记录。

## 错误处理

- 网卡选择错误时，界面提示并禁止启动网关服务。
- WAN 侧无默认网关时，提示用户检查上级路由器连接。
- LAN DHCP 地址池冲突时，禁止保存配置。
- DNS 上游不可用时，自动切换备用 DNS，并记录告警。
- 后台服务异常退出时，管理界面显示离线状态，并提示重启服务。
- 策略配置冲突时，以白名单优先于黑名单，设备策略优先于分组策略。

## 测试与验收

第一版必须完成以下功能可用性测试：

- 网关转发：下级设备可通过本软件正常上网。
- NAT：下级设备访问公网时出口为上级路由器网络出口。
- DHCP：下级设备可自动获取 LAN 网段 IP、网关和 DNS。
- DNS：域名解析正常，查询记录可在界面看到。
- 设备发现：新设备接入后出现在设备列表。
- 实时速率：设备下载/上传时速率图表变化正确。
- 连接统计：访问网站或服务时能看到目标 IP、端口、协议。
- GeoIP：公网目标 IP 显示国家/地区。
- 限速：对指定设备限速后，测速结果接近配置值。
- 黑名单：拉黑设备后无法访问外网。
- 白名单：白名单规则可覆盖普通黑名单规则。
- 端口封禁：封禁指定端口后对应连接被阻断。
- 时间段控制：在禁止时间内设备无法访问外网。
- DNS 黑名单：被拉黑域名无法解析或被重定向阻断。
- 安全告警：模拟端口扫描、异常连接数、命中测试恶意域名时产生告警。
- 报表导出：按时间段导出 CSV，内容包含设备、流量、域名、告警统计。
- 服务稳定性：连续运行 24 小时无崩溃，转发不中断。

## 第一版边界

第一版包含所有主要功能模块，但不包含以下能力：

- 不做 HTTPS 解密。
- 不查看聊天内容、网页正文、账号密码。
- 不保证识别所有 P2P、病毒、挖矿行为，第一版采用规则库和行为特征基础识别。
- 不支持管理未经过双网卡网关转发的设备。
- 不承诺替代专业企业级防火墙的全部能力。

## 交付标准

- 可安装的 Windows exe。
- 后台服务可随系统启动。
- 管理界面可配置网卡、LAN 网段、DNS、DHCP、策略。
- 所有测试与验收条目有测试记录。
- 默认配置能让普通用户按向导完成部署。
